# Taenyun Kim — CV

Edit `CV.tex` and `publications.bib`, then run `bash build.sh` from this directory. The script updates `../assets/CV_Taenyun_Kim.pdf`, which the website links to.

Requires TeX Live with pdflatex, BibTeX, latex-extra, recommended fonts, and datetime. The original unused apacite and kotex imports were removed; the bibliography uses plain.bst.

Commit the source files and regenerated PDF together. Build intermediates are ignored.
